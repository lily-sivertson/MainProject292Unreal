# MainProject292Unreal
This is a stardew valley clone but in 3D made in Unreal Engine 5.4

## Assets

### Sounds

- Pickaxe Sound effect: "Metallic pickaxe 3/4" by TechspiredMinds (https://freesound.org/people/TechspiredMinds/sounds/728758/)
- Axe Sound effect: "chop2.mp3" by igroglaz (https://freesound.org/people/igroglaz/sounds/593857/)
- Rain sound effect: "Rain Falling Hard Outside" by upkey (https://freesound.org/people/upkey/sounds/826327/)

### Textures
- Wood texture: "Light wood 1024x1024" by qubodup (https://opengameart.org/content/light-wood-1024x1024)
